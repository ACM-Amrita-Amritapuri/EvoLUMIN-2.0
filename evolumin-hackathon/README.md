# Evolumin Hackathon (React + Vite)

```
npm install
npm run dev      # local
npm run build    # production build in dist/
```

- Event date: `EVENT` in `src/data.jsx`; registration link: `REGISTER_URL` in the same file.
- Domains, stages, FAQs and sponsors are all in `src/data.jsx`.
- Domain pages use hash routes (`#/domain/ai`), so they work on any static host with no server config.
