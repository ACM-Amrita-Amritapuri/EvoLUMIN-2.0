## Research results you must apply (all verified by research agents; read their prototypes when useful)
Scratchpad (all under `<screenshot scratch dir: any temp folder>`): `r1\s.jsx` (motion snippets compiled against installed motion 14.4), `r2\bg.html` (verified raw-WebGL2 smoke background), `r3\t.html` (verified sticky/CSS-scroll-driven snippets), `r4\proto.html` + `p1_*.png` (verified red/cyan CSS prototypes: light leaks, gradient border, glowing numerals, hairline, rail, button), plus `pw\shot.mjs` (the test harness, below).

1. **three.js is removed.** It was 129 kB gzip for what is one fullscreen shader and one textured logo. Use raw WebGL2 via `src/lib/gl.js` (read it; ~1 kB; it has `program`, `triangle`, `texture`, `loadImage`, `loop`, `tier`, `guardContext`, `reducedMotion`). Both canvases use `{antialias:false}`; the background uses `alpha:false`; the hero needs alpha: write PREMULTIPLIED colour (`o=vec4(rgb*a,a)`) and `gl.blendFunc(ONE, ONE_MINUS_SRC_ALPHA)` or `(ONE,ONE)`; NEVER rely on CSS `mix-blend-mode` under a transformed parent (it silently stops blending and shows a black box). Rules: one rAF loop per canvas that stops when off-screen (IntersectionObserver) or tab hidden; pointer/scroll kept in refs not React state; cap canvas pixels (~1M px for the background; background scale ~0.5); FPS-adaptive scale; handle context loss; dispose with `WEBGL_lose_context`; `prefers-reduced-motion` => render one static frame.
2. **Motion library facts** (installed `motion` 14.4): use `m.*` with the existing `LazyMotion` (`strict`), never `motion.*`. Native off-main-thread scroll animation is only for `opacity/clipPath/filter/transform/backgroundColor` driven by `useTransform(scrollYProgress,[..],[..])` (array in, array out) with edge/percent offsets; `x/y/scale` run in JS (fine for a few elements). No `vh/px` offsets if you want native. Never transform a `useScroll` target or its ancestors. Don't animate width/height/blur; use transform/opacity/clip-path. Wrap `useEffect` `animate()` calls with cleanup `ctrl.stop()` (StrictMode). Cache `getBoundingClientRect` on pointerenter, never per frame. Text scrubbing: one `useScroll`, a `useTransform` per word, `m.span` (see r1/s.jsx).
3. **Pinned scrollytelling is the signature technique**: tall wrapper (e.g. `height:300svh`) containing `position:sticky;top:0;height:100svh` stage; progress via `useScroll({target:wrapperRef,offset:["start start","end end"]})`. NEVER put `overflow:hidden` on html/body or any ancestor of a sticky element (`html{overflow-x:clip}` is fine). `content-visibility:auto` must NOT be applied to pinned wrappers (they need explicit height; set `content-visibility:visible` on them). Use `svh` units. On mobile (<=700px) pinned effects collapse to simple stacked layouts (no horizontal pinning) so nothing breaks.
4. **Gradient colour**: red-to-cyan directly is muddy grey in the middle; use the violet stop: `--light: linear-gradient(100deg,#ff4d5e,#b06cff 50%,#45d0f5)`. Tokens `--ember #ff4d5e`, `--ion #45d0f5`, `--violet #b06cff`. Hot variants for glows: ember rgba(255,77,94,.x) and ion rgba(69,208,245,.x).
5. **Light plan per section** (every section gets two huge static off-canvas radial leaks (`closest-side` radial-gradients ~70vw, `mix-blend-mode:screen`, never animated, section `isolation:isolate`, leaks overlap the section edges ~20svh so hues bleed between sections), plus the fixed WebGL smoke behind everything): Hero: flame is the source (red left, cyan right). ## Logo FX brief (agent 2): the previous effect was "shit"
Problem observed: the old shader warped the logo texture with noise so the crescent/flame shape tore into a smeared, noisy blob and lost its identity. The logo (`public/logo.jpeg`, 1254x1254, black bg; red flame upper-left/top, cyan lower-left arc, crisp bright white-hot core lines with smoky halos) must stay CRISP and RECOGNISABLE and look premium. Build with raw WebGL2 (`lib/gl.js`), one fullscreen-triangle shader pass over the canvas rect:
- Keep the bright core lines sharp: warp amplitude must scale with `(1 - coreMask)` where coreMask comes from luminance/saturation of a mip-blurred sample, so only the smoky outer halo drifts (curl-noise flow, slow), while white-hot edges stay put with at most a subtle shimmer.
- Pseudo-3D depth: N=4 depth slices (loop in the shader; 2 on low tier) sampled at different scales/parallax offsets driven by pointer tilt AND scroll (the logo slowly turns/tilts as the hero scrolls away), with additive combination so it reads as volumetric layered light; slight chromatic edge.
- In-shader bloom: 6-8 taps at higher mip levels (`textureLod`) added for a glowing aura in the logo's own red/cyan (no separate pass).
- Embers: one instanced soft-sprite draw (300 desktop / 120 low tier) rising with curl drift, red and cyan, depth-parallaxed, additive; premultiplied output.
- Idle breathing (slow scale/brightness pulse), pointer tilt with damping; on touch a gentle auto-sway. Loop stops off-screen; `prefers-reduced-motion` => single static frame. Static fallback `<img src=logo-glow.webp>` (transparent webp already in `public/`, keep it) shown until the first frame is ready, then cross-fade out (no black box).
- Composition at 1440x900 and 1920x1080: the flame is BIG (a major part of the hero's right side, ~55-65vh, allowed to bleed past the right edge a little) and never overlaps/hurts legibility of the headline "Fix what's broken.
